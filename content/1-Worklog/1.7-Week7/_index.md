# 7. Learning serverless and reviewing AWS architecture

### Week 7 Objectives:

- Understand the serverless concept and the roles of its basic services.
- Distinguish EC2 servers from the Lambda execution model.
- Consolidate the knowledge gained to prepare for practical work.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| :--- | :--- | :--- | :--- | :--- |
| Saturday (on-site) | Learn about AWS Lambda and event-driven code execution. | 03/10/2026 | 03/10/2026 | [AWS Lambda](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html) |
| Sunday (independent study) | Read how API Gateway accepts HTTP requests and forwards them to a backend. | 04/10/2026 | 04/10/2026 | [Amazon API Gateway](https://docs.aws.amazon.com/apigateway/latest/developerguide/welcome.html) |
| Monday (independent study) | Study DynamoDB, item-based data storage, and the role of primary keys. | 05/10/2026 | 05/10/2026 | [Amazon DynamoDB](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/Introduction.html) |
| Tuesday (independent study) | Review VPC, EC2, IAM, and CloudWatch; compare EC2 operations with serverless services. | 06/10/2026 | 06/10/2026 | [AWS Lambda](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html) |

### Week 7 Achievements:

- Understood the basic roles of Lambda, API Gateway, and DynamoDB.
- Distinguished virtual-server and serverless models.
- Consolidated AWS knowledge from the first seven weeks in preparation for project work.
