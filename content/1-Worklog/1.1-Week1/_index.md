# 1. Getting started with the FCAJ internship and cloud computing

### Week 1 Objectives:

- Become familiar with the internship environment at 36 Cat Linh and its learning approach.
- Understand fundamental cloud computing and AWS concepts.
- Learn how to find documentation and use the AWS Management Console.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| :--- | :--- | :--- | :--- | :--- |
| Saturday (on-site) | Learn about the FCAJ program, the internship environment, and how to maintain a learning log. | 08/08/2026 | 08/08/2026 | [AWS First Cloud AI Journey](https://cloudjourney.awsstudygroup.com/) |
| Sunday (independent study) | Study cloud computing concepts and the IaaS, PaaS, and SaaS models. | 09/08/2026 | 09/08/2026 | [AWS Overview](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html) |
| Monday (independent study) | Learn about AWS Regions, Availability Zones, and global infrastructure. | 10/08/2026 | 10/08/2026 | [AWS Overview](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html) |
| Tuesday (independent study) | Explore the AWS Management Console and the Compute, Storage, Networking, and Database service categories. | 11/08/2026 | 11/08/2026 | [AWS Overview](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html) |
| Wednesday (independent study) | Read the AWS CLI guide and note how to locate documentation for independent study. | 12/08/2026 | 12/08/2026 | [AWS CLI User Guide](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-welcome.html) |

### Week 1 Achievements:

- Gained introductory knowledge of cloud computing and AWS service categories.
- Understood the distinction between a Region and an Availability Zone.
- Established an approach to independent study and AWS documentation for later weeks.
