# 2. Learning IAM, account security, and cost management

### Week 2 Objectives:

- Understand the fundamental components of AWS IAM.
- Learn how to secure accounts and manage access.
- Learn how to monitor AWS service costs.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| :--- | :--- | :--- | :--- | :--- |
| Saturday (on-site) | Learn about IAM users, groups, roles, and policies during the internship session. | 29/08/2026 | 29/08/2026 | [AWS IAM](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html) |
| Sunday (independent study) | Study MFA and least privilege, and learn why root account usage should be limited. | 30/08/2026 | 30/08/2026 | [IAM security best practices](https://docs.aws.amazon.com/IAM/latest/UserGuide/best-practices.html) |
| Monday (independent study) | Study the shared responsibility model between AWS and its customers. | 31/08/2026 | 31/08/2026 | [Shared responsibility](https://docs.aws.amazon.com/wellarchitected/latest/framework/shared-responsibility.html) |
| Tuesday (independent study) | Read how to track costs and configure budget notifications using AWS Budgets. | 01/09/2026 | 01/09/2026 | [AWS Budgets best practices](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-best-practices.html) |

### Week 2 Achievements:

- Distinguished between IAM users, roles, and policies.
- Understood basic AWS account security principles.
- Learned how AWS Budgets can be used to monitor lab costs.
