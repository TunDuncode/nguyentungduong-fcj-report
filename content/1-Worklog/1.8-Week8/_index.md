# 8. Researching project technologies as a team

### Week 8 Objectives:

- Explore network infrastructure management and monitoring technologies as a team.
- Research AWS services relevant to the assigned responsibilities.
- Discuss the advantages of the serverless model.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| :--- | :--- | :--- | :--- | :--- |
| Saturday (on-site) | Meet as a team and discuss cloud-based network infrastructure management and monitoring technologies. | 10/10/2026 | 10/10/2026 | [AWS Overview](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html) |
| Sunday (teamwork) | Research Amazon VPC and how to build virtual network infrastructure for the project. | 11/10/2026 | 11/10/2026 | [VPC](https://docs.aws.amazon.com/vpc/latest/userguide/how-it-works.html) |
| Monday (teamwork) | Learn about Amazon EC2 and how virtual servers can be used in a monitoring system. | 12/10/2026 | 12/10/2026 | [EC2](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/LaunchingAndUsingInstances.html) |
| Tuesday (teamwork) | Research the serverless model with Lambda, API Gateway, and DynamoDB as a team. | 13/10/2026 | 13/10/2026 | [Lambda](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html) |

### Week 8 Achievements:

- Understood the technologies that could be used in the project.
- Learned the roles of VPC, EC2, and serverless services.
- Shared research findings with team members to select suitable technologies.
