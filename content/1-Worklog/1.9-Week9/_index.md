# 9. Team discussion on applying AWS services to the project

### Week 9 Objectives:

- Study how AWS services work together as a team.
- Explore methods for securing and monitoring network infrastructure.
- Discuss architectural options before implementation.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| :--- | :--- | :--- | :--- | :--- |
| Saturday (on-site) | Meet as a team and discuss solutions for building and monitoring infrastructure on AWS. | 17/10/2026 | 17/10/2026 | [FCAJ](https://cloudjourney.awsstudygroup.com/) |
| Sunday (teamwork) | Study the use of public subnets, private subnets, route tables, and internet gateways for the project. | 18/10/2026 | 18/10/2026 | [VPC](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-subnet-basics.html) |
| Monday (teamwork) | Learn how to secure servers using IAM and security groups. | 19/10/2026 | 19/10/2026 | [VPC Security](https://docs.aws.amazon.com/vpc/latest/userguide/infrastructure-security.html) |
| Tuesday (teamwork) | Discuss with the team how CloudWatch and SNS can work together to monitor resources and send alerts. | 20/10/2026 | 20/10/2026 | [CloudWatch](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch_Alarms.html) |

### Week 9 Achievements:

- Understood the relationships between AWS services.
- Learned methods for securing and monitoring infrastructure.
- Established a direction for technology selection and system architecture with the team.
